# Parasync

## 專案簡介

Parasync 是一個專為 Unity 連線遊戲開發設計的輕量級狀態同步框架。

### 設計理念

**輕量化**：架構去蕪存菁，將設計簡化至極致，只保留核心功能。

**易用性**：使用者無需複雜配置，只需在程式碼中標記要同步的參數，框架即可自動處理狀態同步。

**模組化**：各個模組採用分離式設計，提供最大程度的客製化彈性，能夠靈活應對各種專案需求。

## 主要功能

- **即時狀態同步**：自動同步標記的參數狀態
- **傳輸狀態監控**：即時監控網路傳輸狀態
- **自動序列化/反序列化**：無需手動處理資料轉換
- **使用者 ID 管理**：內建使用者身份管理機制

## 技術棧

- 語言/框架：C#、Unity、KCP
- AI 協作工具：Cursor、ChatGPT、Claude Code
